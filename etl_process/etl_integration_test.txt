  psql -h localhost -U postgres -d oltp_db -c "SELECT * FROM pg_replication_slots;"

  EOF

──────────────────────────────────────

Create Connector Configuration:

{
  "name": "postgres-oltp-connector",
  "config": {
    "connector.class": "io.debezium.connector.postgres.PostgresConnector",
    "database.hostname": "localhost",
    "database.port": 5432,
    "database.user": "postgres",
    "database.password": "postgres",
    "database.dbname": "oltp_db",
    "database.server.name": "debezium.oltp",
    "plugin.name": "pgoutput",
    "slot.name": "debezium_slot",
    "publication.name": "debezium_pub",
    "transforms": "route",
    "transforms.route.type": "org.apache.kafka.connect.transforms.RegexRouter",
    "transforms.route.regex": "([^.]+)\\.([^.]+)\\.([^.]+)",

EOF

TROUBLESHOOTING COMMON ISSUES
================================================================================

ISSUE: Kafka Consumer Lag High
──────────────────────────────

Symptoms:
  - Airflow task consuming events takes > 1 hour
  - Kafka consumer lag > 10000 messages

Diagnosis:
  kafka-consumer-groups.sh --group etl_pipeline_consumer_group \
    --describe --bootstrap-server localhost:9092

Resolution:
  1. Check OLAP database performance: Is insert slowing down?
  2. Reduce batch size in config/database.yaml (BATCH_SIZE=1000 → 500)
  3. Check disk I/O: iostat or Performance Monitor
  4. Increase Airflow task timeout in DAG

ISSUE: Data Quality Checks Failing
──────────────────────────────────

Symptoms:
  - quality_checks task in Airflow fails
  - NULL or duplicate values detected

Diagnosis:
  1. Check Airflow task logs: $AIRFLOW_HOME/logs/[dag]/quality_checks/
  2. Query the failing table: SELECT * FROM [table] WHERE [check_condition]
  3. Check Python transformers: Are they handling NULL values?

Resolution:
  1. Fix transformer logic in src/transformers.py
  2. Re-run unit tests: pytest tests/
  3. Truncate affected table: TRUNCATE TABLE [table];
  4. Re-trigger Airflow DAG

ISSUE: Python Pipeline Crashes
───────────────────────────────

Symptoms:
  - Airflow task fails with Python exception
  - No data loaded to OLAP

Diagnosis:
  1. Check Airflow task logs for stack trace
  2. Verify database connectivity: psql -h localhost -U postgres
  3. Check Kafka connectivity: python -c "from kafka import KafkaConsumer"
  4. Check file permissions: ls -la etl-pipeline/

Resolution:
  1. Fix Python code based on error message
  2. Re-run unit tests locally
  3. Re-trigger Airflow DAG

ISSUE: Airflow DAG Not Triggering
──────────────────────────────────

Symptoms:
  - DAG listed but not executing
  - No logs in $AIRFLOW_HOME/logs/

Diagnosis:
  1. Check scheduler running: ps aux | grep "airflow scheduler"
  2. Check DAG syntax: python $AIRFLOW_HOME/dags/oltp_to_olap_dag.py
